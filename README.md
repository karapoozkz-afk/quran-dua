# Библия: что читать сегодня — Android

Офлайн-Библия, которая отвечает на вопрос «что мне прочитать в моей ситуации?». Синодальный перевод и King James Version, 30 жизненных тем, 170 отрывков, стих дня, план «Библия за год», чтение вслух голосом телефона. Без интернета, рекламы и сбора данных.

Сделано на той же основе, что «Коран и Дуа», с учётом того, что мешало Корану пройти Google Play: см. [LESSONS.md](LESSONS.md). Как выпустить: [RELEASE.md](RELEASE.md).

## Что есть

- **Что читать**: 30 тем (тревога, утрата, болезнь, долги, прощение, брак, дети, дорога, сон…) и 170 отрывков. Поиск понимает фразы: «мне тревожно», «умер отец», «my father died».
- **Полный текст**: Синодальный перевод (77 книг, неканонические помечены и скрываются) и KJV (66 книг). Порядок книг как в каждом издании.
- **Переход по ссылке**: «Ин 3:16», «иоанна 3 16», «1 Кор 13:4-7», «Пс 22», «John 3:16».
- **Поиск по тексту** всей Библии.
- **Стих дня** на главной и в уведомлении в выбранное время (неточный будильник, без особых разрешений).
- **Библия за год**: 365 дней, главы распределены по объёму текста; нумерация Псалмов пересчитывается для Синодального перевода.
- **Слушать главу** голосом синтеза речи телефона, с подсветкой текущего стиха.
- Закладки, сохранённые отрывки, «Продолжить чтение», размер шрифта, светлая и тёмная тема, русский и английский интерфейс.

## Нумерация Псалмов

Синодальный перевод нумерует Псалмы по греческой Псалтири, KJV по еврейской: Синодальный 22 = KJV 23, 50 = 51, 90 = 91. У каждого отрывка две ссылки, по одной на перевод. `tools/build_content.py` не соберёт контент, если глава в переводах пронумерована по-разному, а английская ссылка не указана явно.

## Структура

```
shared/                 модуль KMP: модели, поиск, разбор ссылок, Room, строки интерфейса
androidApp/             Jetpack Compose, Material 3
  src/main/assets/content/   books, bible_ru, bible_en, situations, passages, votd, plan (собираются скриптом)
content-src/            темы, отрывки, стихи дня: только ссылки, без текста Писания
tools/                  books.py (список книг), build_content.py (сборка и проверки)
docs/                   карточка Google Play, политика конфиденциальности
```

## Сборка

Нужны JDK 17 и Android SDK 36.

```bash
./gradlew :shared:testDebugUnitTest      # тесты: поиск, ссылки, сверка цитат с текстом, план
./gradlew :androidApp:assembleDebug      # APK для телефона
./gradlew :androidApp:bundleRelease      # .aab для Google Play (подпись: RELEASE.md)
```

GitHub Actions (`.github/workflows/build.yml`) делает всё это на каждый push в ветку `bible` и выкладывает APK и AAB в релиз `bible-latest`.

## Тексты и лицензии

- Синодальный перевод (1876) и King James Version (1769): общественное достояние. Электронный текст: CrossWire Bible Society через [scrollmapper/bible_databases](https://github.com/scrollmapper/bible_databases).
- Квадратные скобки в Синодальном тексте («[И увидел Бог, что это хорошо.]») — часть самого перевода: так он отмечает слова из греческого текста.
